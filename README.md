# Winnie's Cat Diary

Winnie's Cat Diary is a simple Flutter app for saving cats you meet, adding names, places, notes, photos, and feeding them virtually.

## Features

- Cat album
- Add cat photo from camera or gallery
- Manual place entry
- Notes
- Last seen date
- Virtual feeding interaction
- Share cat photo and details
- English and Turkish language support
- Local storage

## Privacy

The app stores cat album data locally on the device. It does not require an account or GPS location permission.
